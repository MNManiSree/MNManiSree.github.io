# Naga Mani Sree – Portfolio

Personal portfolio website for Manunuru Naga Mani Sree, an entry-level software engineer based in Hyderabad, India.

Built with plain HTML, CSS and JavaScript (no frameworks or build step). It is responsive, supports light and dark mode, and includes a small accent-colour picker that recolours the page from a single CSS variable.

## Sections
- Selected work (Java/Spring Boot, Django and deep learning projects)
- Skills
- About, certifications and education
- Contact

## Run locally
Open `index.html` in any browser.
